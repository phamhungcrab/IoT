# IoT Smart Home

A smart-home project based on ESP32 for monitoring and controlling household devices.

## Goals

- Monitor environmental conditions.
- Control electrical devices remotely.
- Provide reliable Wi-Fi connectivity.
- Exchange data between IoT devices and a central system.
- Provide a simple monitoring dashboard.

## Planned Modules

- ESP32 Wi-Fi connectivity
- Automatic Wi-Fi reconnection
- Temperature and humidity sensing
- Relay control
- MQTT communication
- Basic dashboard

## Project Structure

The project is currently under development. Source code, hardware documentation,
and setup instructions will be added as individual modules are implemented.
